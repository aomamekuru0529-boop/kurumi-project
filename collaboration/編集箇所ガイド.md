# 編集箇所ガイド

| 変更したい内容 | 編集するファイル | 目安 |
| --- | --- | --- |
| 質問・回答・妖精の紹介文 | experience.js | questions、typesを編集 |
| 会社名・感謝文・保存カードのURL・音源 | config.js | 空欄の項目は省略や既定値になる |
| 導入画面やボタンの文言・HTML構成 | index.html | idはJSで使用するため、変更時はapp.jsも確認 |
| 深緑・金色の配色、フォント、文字の配置 | design.css | styles.cssより後に読み込むデザイン調整 |
| レイアウト・吹き出し・光・アニメーション | styles.css | 同じ指定が複数ある場合は後の指定が優先 |
| 画面の切り替え・演出の秒数・なで操作 | app.js | laterの時間はミリ秒。1000=1秒 |
| プレゼントの箱・リボン・装飾 | gift.js | SVGで描画 |
| 光の妖精・成長後の妖精 | fairy.js | SVGで描画 |
| 3Dの村・家・木・照明・カメラの移動 | tour.js | Three.jsの立体モデル |
| WebGL非対応時の見渡す背景 | panorama.js | Canvasによる代替表示 |
| スマホの姿勢から視線方向を計算 | orientation.js | 変更後は縦横・360°境界を確認 |
| 音楽・ベルの旋律 | audio.js | 外部音源はconfig.jsのbgmUrl |
| 保存カードの画像デザイン | card.js | CSSの画面とは別のCanvas描画 |
| 自作画像・音源 | assets/ | フォルダを作って追加。ビルド時にdistへコピー |

## よく調整する演出

- app.jsのanswer：回答から箱へキラキラが届くタイミング。
- app.jsのfinishQuiz：プレゼント完成、揺れ、爆発までの流れ。
- app.jsのaddStroke／transformFairy：なで操作の進捗と進化。
- styles.cssの `--power-progress`：なでる途中の光の強さ。
- styles.cssのevolutionBloom／evolutionRing：進化の瞬間の光。
- app.jsのgoToWorkshopとtour.js：妖精について工房へ移動。

## 調整後の確認

1. 最初の画面から妖精を探して工房へ進む。
2. 4問に答え、各回答のキラキラとプレゼントの変化を確認。
3. 爆発後の文章、なでる光、進化、紹介カードを確認。
4. 感謝カード、保存画像、もう一度遊ぶ動作を確認。
5. 狭い画面でも文字とボタンが見切れないか確認。

必要に応じて `node --test tests/experience.test.mjs tests/orientation.test.mjs` で計算処理を検証できます。
ブラウザ自動テストを行う場合は `npx playwright install chromium` の後、`APP_ROOT=dist npm test`（Mac/Linux）を実行します。Windows PowerShellでは `$env:APP_ROOT='dist'; npm test`。
